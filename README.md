# JSCII

ASCII wasn't enough, so I made my own.

JSCII is a custom character encoding format inspired by ASCII, built as a Python project and deployed as a Streamlit web app.

## Try It

https://jscii-web.streamlit.app/

## What Makes It Different?

- Custom character mapping
- Signature verification
- Randomized output bits
- Browser-based encoder/decoder

## Built With

- Python
- Streamlit

## Status

Just for fun, learning, and experimentation.
